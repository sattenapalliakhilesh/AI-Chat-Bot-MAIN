Must run before anything else that needs the key. pythonapp = Flask(__name__) Creates your web application. __name__ tells Flask where your project folder is so it can find your templates and static files. Everything in your app runs through this app object. pythonapp.secret_key = secrets.token_hex(24) Flask needs a secret key to encrypt session cookies. secrets.token_hex(24) generates a random 48-character string every time the app starts. It automatically picks up your API key from the .env file because you called load_dotenv() earlier. The data stores pythondocument_store = {} conversation_store = {} Two empty Python dictionaries that live in server memory. document_store holds uploaded document text. conversation_store holds chat history. Both use the session ID as the key — like a locker number — so each user's data stays separate. The PDF function pythondef extract_text_from_pdf(file): reader = PdfReader(file) text = "" for page in reader.pages: text += page.extract_text() or "" return text A reusable function that takes a PDF file as input. PdfReader(file) opens it. reader.pages is a list of every page. The for loop goes through each page and adds its text to the text variable. or "" means if a page has no text, add an empty string instead of crashing. Returns the full text at the end. The reset route python@app.route("/reset", methods=["POST"]) def reset(): session_id = session.get("session_id") if session_id: document_store.pop(session_id, None) conversation_store.pop(session_id, None) session.clear() return jsonify({"success": True}) Cleans up everything when the user clicks "Clear & start over". .pop(session_id, None) removes the entry from the dictionary — the None means don't crash if the key doesn't exist. session.clear() wipes the browser cookie.
